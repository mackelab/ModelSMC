# Fig_1_overview_ModelSMC

## Icons

`plot_panel_a.ipynb` and `plot_panel_a_extended.ipynb` embed eight vector icons into the
saved SVG. The icons are from [uxwing.com](https://uxwing.com/) and are used under the
[UXWing license](https://uxwing.com/license/). They are **not checked in** and are not
covered by this repository's MIT License.

To re-run those notebooks, download the eight icons from
[uxwing.com](https://uxwing.com/) — the file names below are the site's own slugs — and
place them, unmodified, in `notebooks/icons/`:

```text
notebooks/icons/
├── atom-laboratory-science-icon.svg
├── bacteria-infection-virus-icon.svg
├── database-line-icon.svg
├── female-icon.svg
├── file-line-icon.svg
├── flask-icon.svg
├── monitor-icon.svg
└── web-code-icon.svg
```
